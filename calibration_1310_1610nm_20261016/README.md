# 1310 / 1610 nm 硅基 D2NN 局部标定

采用 Lumerical v241 的 MODE FDE 和 TE varFDTD，分别标定 O 波段的 1310 nm 与 L 波段的 1610 nm。两波长相差 300 nm，使用相同器件材料和几何。原项目的 1560 nm map、训练数据、编码器和模型保持原有文件。

2026-10-16 已完成两个波长各 21 点的扫描，以及网格/时长复核。结果如下。

| 标定结果 | 1310 nm | 1610 nm |
|---|---:|---:|
| TE 有效折射率实部 | 2.982975 | 2.795768 |
| 有效折射率虚部（Palik 模型） | 0 | 0 |
| 候选相位系数 μm/π | −0.432998 | −0.575231 |
| 相位斜率 π/μm | −2.309478 | −1.738431 |
| 线性拟合 R² | 0.999652 | 0.999421 |
| 最大相位拟合残差 | 0.04163π | 0.03850π |
| 相对场振幅范围 | 0.80109–1.00000 | 0.80315–1.00000 |
| 网格/时长复核最大相位差 | 0.00235π | 0.00312π |
| 网格/时长复核最大振幅绝对差 | 0.000309 | 0.000506 |

两个波长的相位都接近线性，网格/时长复核通过。不过槽长改变时场振幅会降低约 20%，不满足本文所设的 ±10% 纯相位近似筛选条件。下游优先采用保存的复响应表，并保持两个波长共享同一个物理槽长，不能分别给同一个槽赋两个独立几何参数。理想材料模型无体吸收不等于槽阵列无反射或真实器件无损耗。

范围为**TE 平板导模 + 横向周期槽单元的局部复响应**。结果尚不是完整 500 μm 网络的映射包，也没有执行 1310/1610 nm 分类训练或完整三维 FDTD 器件验证。

一维求模使用远离硅层的金属边界，并直接检查边界距离影响；前次 780 nm 工作中本机 v241 的一维 PML 求模出现过非有限场。此次分别在两个通信波长检查导模场有限性，不沿用 780 nm 或 1560 nm 的有效折射率、相位系数。

本次几何包含氧化硅衬底和氧化硅槽填充。旧标定生成器中省略衬底、使用空气刻蚀的设置未作为此次最终物理设置。

## 复响应定义

`relative_complex_transmission = mean(H_out, slot) / mean(H_out, no slot)`。

对每个槽长使用相同入射光源，输出场相对于无槽输出归一化。周期单元的传播方向外部只保留零级传播分量，取横向平均场得到该分量。上游总场包含入射和反射的干涉，不能作为每点的入射场幅度；`scan_points.json` 中的 `transfer_abs` 仅保存上游/下游总场诊断比值，不是用于归一化的量，也不是绝对效率。

振幅是相对复场的模。其平方仅能用于在相同外部模式和相同入射条件下比较局部单元相对功率，不代表完整器件端口的绝对效率。

相位按槽长解缠，以 π 为单位作普通最小二乘拟合。`mapping_factor_um_per_pi` 是拟合斜率的倒数，保留符号；它只是线性概括，使用时需同时查看拟合残差、振幅变化和数值复核。

采用的纯相位近似筛选条件为 R²≥0.99、最大残差≤0.1π、相对场振幅均位于 0.9–1.1。局部网格/时长复核采用相位差≤0.02π、振幅绝对差≤0.03；这些是本次明示的工程筛选阈值，不是普适物理标准。

Palik 材料在某波长给出零虚部时，报告中的零吸收仅对应该材料模型；不包括粗糙度散射、自由载流子吸收、实际工艺缺陷、输入输出耦合等损耗。

## 文件

- `calibration_comparison.json`：两波长完整结果。
- `calibration_parameters.json`：两波长有效折射率和候选相位系数字典，以及复响应表的相对路径；不是完整网络 map。
- `calibration_comparison.png`：两波长相位、拟合线和振幅对比图。
- `wl1310nm/`、`wl1610nm/`：各波长的原始点、复响应 NPZ/CSV、求模检查、网格/时长复核、状态和 LSF。
- 各波长 `solver_files/`：主要 Lumerical 工程、模式场及求解日志。

开发中中断的扫描保留于本地工作区的 `previous_attempt_*`，仅作诊断。归档交付选择最终结果与可复现源代码，不包含该中间扫描。

## 重跑

需要 Python 的 numpy、matplotlib，以及可用的 Lumerical MODE/varFDTD 许可证。接口路径固定为 `D:\Program Files\Lumerical\v241\api\python\lumapi.py`；原项目路径见 `config.json`。

```powershell
python -B -u run_calibration.py prepare
python -B -u run_calibration.py run
python -B -u run_calibration.py analyze
```

`prepare` 生成配置与 LSF；`run` 按顺序求模、扫描并复核，已完整完成的波长会复用其结果；`analyze` 从保存的 JSON 点表重新计算统计、NPZ、CSV 和对比图，无需启动求解器。可用 `--wavelength-nm 1310` 或 `--wavelength-nm 1610` 仅运行一个波长。

求解器中间文件使用 ASCII 临时目录，主要工程文件会复制到输出目录。所有正式科学结果均可由保存的原始点表重新生成，不依赖临时目录继续存在。

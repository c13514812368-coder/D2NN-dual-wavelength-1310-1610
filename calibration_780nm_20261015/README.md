# 780 nm 硅基 D2NN 局部标定

本目录针对原 1560 nm 场景三分类副本的材料与几何，在 Lumerical v241 中重新求解 780 nm 导模，并扫描周期槽阵列的局部复响应。原训练数据、1560 nm map 和模型检查点均不作为本次输出覆盖目标。

2026-10-15 已完成全部 21 点扫描，实际采样波长为 **780.0 nm**。全区间相位拟合的候选系数为 **−0.390961 μm/π**，斜率 **−2.557800 π/μm**，R² 为 **0.998977**，最大残差 **0.109338π（约 19.7°）**。相对场振幅范围为 **0.357532–1.046199**，不满足本次纯相位近似的判据。

这是**导模与局部槽响应标定**，不包含完整 500 μm 网络的 map、780 nm 训练或分类准确率。varFDTD 属于有效折射率近似；本结果也不是全三维 FDTD 器件验证。

## 材料和几何

原始结构来源于项目 `map/shape_spec.json`，其 SHA256 记录在 `config.json`。

- 波长：780 nm，实际监视器频率另在 `solver_settings.json` 核验。
- 硅材料：`Si (Silicon) - Palik`，硅层厚度 220 nm。
- 衬底和槽填充：`SiO2 (Glass) - Palik`，衬底厚度 2 μm，上包层为空气。
- 槽宽 150 nm，周期 300 nm；槽长 0–2 μm，步长 0.1 μm，共 21 点。
- 局部 varFDTD 使用宽 300 nm 的横向周期单元、纵向 8 μm 的计算区，网格精度 7；监视器在传播方向 ±2.5 μm，光源在 −3.5 μm。
- 光源为 20 fs 脉冲，延迟 60 fs，中心 780 nm；最长仿真时间 500 fs，自动停止阈值 1e-7。在中心波长提取单频复场。

原标定生成器没有衬底，槽材料写为 `etch`。本次脚本根据项目的结构记录补齐氧化硅衬底并使用氧化硅槽填充。因此本结果对应记录中的器件材料，不能理解为对原标定脚本仅替换波长。

## 模式求解与数值检查

1D FDE 使用 2000 个 z 网格点、z 范围 ±1 μm、远离芯层的金属边界、6 个试探模式、搜索折射率 3.4。1000 点网格结果同时保留用于收敛检查。

本机 v241 的 1D PML 设置返回 NaN 模式场，已明确判为无效。金属边界得到有限导模场；另用 2D 截面求解交叉检查，记录在 `solver_checks.json`。没有把无效 PML 的输出用于最终标定。

求得有效折射率约 `3.462204 + 0.007708i`，1000/2000 点网格差约 `2.77e-5`。导模损耗约 **0.539 dB/μm**，若保持原硅材料并传播 500 μm，仅该吸收损耗估计约 **269.7 dB**。因此原 500 μm 硅器件在 780 nm 下不适合作为低损耗器件直接沿用。

局部复传递量使用输出/输入监视器的横向场投影，并相对于无槽基线归一化。`relative_complex_transmission` 是相对复场响应，其模平方不能直接解释为整个器件端口的绝对功率效率。无槽 5 μm 传播的 varFDTD 振幅与复有效折射率预测还会作独立交叉检查。

本次无槽基线场振幅为 **0.731828**，FDE 预测为 **0.733109**，差约 **0.175%**。相邻采样点最大解缠相位增量为 **0.4018π**。这些检查支持本次中心频率的数值一致性；局部 varFDTD 槽响应尚未做完整 3D FDTD 或额外网格收敛扫描。

## 输出

| 文件 | 内容 |
|---|---|
| `calibration_results.json` | 最终折射率、损耗、相位斜率、候选 μm/π 系数、拟合残差和适用性判据 |
| `complex_transmission.csv` | 21 点槽长、相对复场实部/虚部、输出/输入监视器绝对场传递量 |
| `calibration_response.npz` | 复响应、解缠相位及拟合曲线，便于后续建模 |
| `calibration_780nm.png` | 槽长—相位及相对振幅曲线 |
| `mode_probe.json` | 有效导模和网格收敛检查 |
| `solver_settings.json` | 光源频率和实际监视器采样频率 |
| `config.json` | 完整原结构和此次局部标定设置 |
| `neff_780nm.lsf` / `mapping_780nm.lsf` | 实际求解脚本 |
| `solver_files/` | 求模工程、模式场、局部标定工程和引擎日志副本 |

`mapping_factor_um_per_pi` 是全区间线性拟合的候选系数。只有同时查看 `local_linear_phase_fit_acceptable`、振幅变化和损耗，才能决定下游模型是否可以采用它。脚本保留完整复响应，不把标定拟合自动写入原项目的纯相位模型。

## 重跑

需要本机可用的 Lumerical MODE/varFDTD 许可证，以及 Python 的 numpy、torch、scipy、pyyaml、matplotlib。接口使用 `D:\Program Files\Lumerical\v241\api\python\lumapi.py`。

在本目录执行：

```powershell
python -B -u run_calibration.py prepare
python -B -u run_calibration.py calibrate
```

`prepare` 只生成配置与 LSF；`calibrate` 重新求模并扫描，会更新本目录的 780 nm 输出。`probe` 只求模；`scan` 复用本目录已验证的导模记录后重新扫描；`analyze` 对 `solver_settings.json` 指向的已完成扫描重新生成统计和图。诊断入口 `solver-check` 保留了 1D/2D、PML/金属边界的对照。

脚本从原项目读取源代码和结构文件，求解中间文件使用 ASCII 临时目录，以避免引擎对中文路径的兼容问题；最终主要工程文件另复制到 `solver_files/`。`active_run.json` 记录最近一次运行状态。

后续若更换为 780 nm 低损耗材料（例如合适工艺的 SiN），需要重新确认材料、厚度、波导模式和槽几何，再独立标定。该选择属于器件设计变更，本次未作替换。

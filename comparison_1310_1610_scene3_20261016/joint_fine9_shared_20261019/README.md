# 共享槽结构的 1310/1610 nm 联合九分类

入口为上一级的 `run_joint_fine9.py`。两个波长处理同一张图、同一份冻结的 16 维九类相位编码，共享唯一一套 3×555 槽长，并通过固定等功率端口强度求和共同给出九分类结果。

每个载波占总输入功率的一半；先相加强度，再在前九个输出端口归一化。不相加不同频率的复电场，不使用可训练电子读出，不将两套独立训练的槽结构称为同一个器件。

从项目根目录运行：

```powershell
python comparison_1310_1610_scene3_20261016/run_joint_fine9.py
```

默认固定种子 42/43/44、20 轮，复用原 7200/1260 训练/验证划分与局部电磁标定。模型采用解析输入、输出模式及标量角谱传播，未执行完整器件 FDTD。运行时的完整参数、输入和代码校验值、软件版本写入 `config.json`。

最终结果和适用范围见 [REPORT.md](REPORT.md)；该报告由实际完成的检查点和预测文件生成。`summary.json` 为机器可读汇总；`seed*/` 包含共享槽长、逐轮记录、验证预测以及同一槽结构下两个波长各自的 10×16 复传输矩阵。

`--preflight-only` 核对功率、共享参数和梯度；`--analysis-only` 使用已有检查点重新验证并生成报告。双波长联合训练与分别训练的单波长基线均有 1665 个可训练槽长；报告另列的“两套结构求和”参考使用两套槽长，共 3330 个参数。

该实验完成共同九分类，没有规定粗分、细分波长分工。当前验证集用于挑选最佳轮次，结果不是独立测试成绩。
